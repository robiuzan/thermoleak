# 🧩 Website Brief Template

> **What this is.** A single, reusable intake document. Fill it in for any service business and
> hand it to me — it contains everything I need to design and build an excellent website from A→Z.
> You don't have to fill *everything*: anything left blank falls back to a sensible default
> (see **Part K**).

---

## How to use this template

1. **Copy** this file to a new name per project (e.g. `acme-plumbing-brief.md`).
2. **Fill** the fields. Replace the `> _…_` prompt lines with your answers.
3. **Skip** what you don't know — I'll either use a smart default or ask you only about what's
   blocking the build.
4. **Hand it to me.** I'll summarize it back, confirm assumptions, then build (see `README.md`).
